# Agentic_AI
I am creating the project to build my first agent on CSV files

Workflow:

    User uploads CSV
        ↓
    CSV saved locally
        ↓
    Agent created dynamically
        ↓
    CsvTools reads structure
        ↓
    User asks question
        ↓
    Agent inspects columns
        ↓
    CsvTools executes query
        ↓
    LLM explains result
